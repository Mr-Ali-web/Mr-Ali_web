## 💫 About Me
I'm a second-year Software Engineering student at **PDP University** (Tashkent). I build web products with a Python backend and a polished frontend, and I like projects that feel alive: 3D scenes, games and real marketplaces for Uzbekistan. I'm the co-founder of **StudentBridge** and I take part in hackathons.
